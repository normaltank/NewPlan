# Mission B 精简分发版 1.0.2 · 维护说明

使用者只需 **选择文件 → 开始核验 → 下载结果**。使用现有 3.0.2 核验引擎，包含静态零链接时的浏览器渲染修复；分页、去重和逐链接比较规则不变。本地完整版及历史数据独立保留。

## 分发

将 `release/MissionB-Lite-Windows-x64-v1.0.2.zip` 完整解压到可写文件夹，双击 `名单核验.exe`。Windows 64 位包自带 Python 与浏览器，包含所有者在本次会话中指定的分发密钥。使用者无需输入密钥，也看不到 API 设置、用量、历史列表、结果统计或详细证据。必要的运行状态、停止与退出仍保留。关闭网页不退出后台。

进度条显示实际完成项数与百分比，刷新后恢复；每个核验分组完成后更新，不估算剩余时间。单个分组处理期间数值可能保持不变。整理下载文件时显示等待状态，文件可下载后才显示 100%。停止或失败后不保留完成进度。

支持文件多选和可折叠的粘贴输入；文本、CSV、TSV、XLSX、XLS 与原有双表规则保持一致。输入模板可直接下载。最近一次状态和下载可在刷新或重新打开后恢复。

分发给使用者的说明仅列操作步骤与日志位置。本文件属于维护文档，不放入 Windows 用户包。请使用干净发行包分发，不复制已经运行的文件夹。

## 结果边界

结果 ZIP 包含 `核验汇总.xlsx` 和已完成分组的核验后链接表。汇总四列固定为 **大学名、学院名、核验结果、特殊情况说明**。结果沿用 **正确／错误／特殊情况** 三类；说明列全部留空。特殊情况只提示人工查看原网页。

精简版只隐藏原因，不改变判定。缺少原因仍不能判为正确或错误；数量相等而 URL 不同仍判错。已有独立分组确认差异时的学院合并规则保持不变。未完成分组不生成空修正表、不清空原始链接。下载不包含详细对账、证据或模型记录。输入原件不改写。

## 日志与复现

软件根目录自动创建并追加 `MissionB.log`，用户遇到问题发回此文件即可。包含版本、代码指纹、解析后的输入、来源 URL、配置、结果、失败堆栈，以及已取得的网页和模型请求／响应证据。日志过滤实际运行密钥、会话令牌和授权字段，不记录授权请求头。证据采用压缩编码，仍在同一个日志文件内。

本地运行数据单独放在 `lite-data`，不读取或改写完整版的 `data`。未取得的网页、突然退出前未写入的证据、变化后的外部服务，不能靠日志保证重现。原始 Excel 文件另在本地保留，日志包含解析后的行和来源定位。

维护环境执行 `python read_lite_log.py MissionB.log 新建证据目录`，默认还原最后一批；`--job-id` 指定任务。该工具只读取日志，不联网、不调用模型。`run.json` 包含输入与环境，`evidence` 保留网页、模型和结果材料。需要排查输入文件本身时，再向使用者索取原件。

## 配置与构建

开发时运行 `python lite_app.py`，使用 `DEEPSEEK_API_KEY` 或未入库的 `lite_config.json`。Windows 发行包从 `_internal/lite_config.json` 读取预配置密钥，只在服务端使用，不通过网页或状态接口返回。网页不能修改密钥或切换引擎。

分发密钥的维护副本通过 Windows 当前用户加密，保存在 `%LOCALAPPDATA%/MissionB-Maintenance/distribution-key.dpapi`，不写进代码或文档。构建使用独立环境：

```powershell
.lite-build-env/Scripts/python.exe build_lite.py --key-dpapi "$env:LOCALAPPDATA/MissionB-Maintenance/distribution-key.dpapi"
```

构建仅复制白名单文件，浏览器从 3.0.1 正式包核验哈希后复用，不携带本地任务或缓存。Windows 包按本次授权携带分发密钥；维护源码 ZIP 不携带密钥，需要维护人员自行配置。源码 ZIP 不包含跨平台自动安装器，未做 Mac/Linux 实机验收。

新版验证与截图见 [1.0.2 验证记录](validation/lite-20261023/README.md)；首次分发及日志复现记录保留在 [1.0.1 验证记录](validation/lite-20261022/README.md)。带预配置密钥的 Windows 包仅用于所有者指定的本地分发，不上传公开源码仓库；源码 ZIP 不含密钥。
