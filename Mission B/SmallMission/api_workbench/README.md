# Mission B 3.0.2 — API 辅助链接核验

独立运行的师资名单 URL 核验工具。支持粘贴文本、CSV、XLSX/XLS，以及“个人url＋师资url”双表格式。输入可包含多个学院，工作台显示缺少、多出和无法判定的原因，并提供四列核验汇总表、分学院修正表、逐条来源证据。

只需要导入和下载的使用者可使用独立的[精简分发版](README_lite.md)。下文仍为本地完整版说明。

本地源码 3.0.2 修复了静态页面零链接时未尝试浏览器渲染的问题；浏览器仍读不到有效名单时继续交给人工，不按零链接清空原表。实际 20 学院基线、抽查和复测见[2026-10-22 维护记录](maintenance/20261022-college-list/README.md)。精简分发版 1.0.3 包含此修复、实际进度条及特殊情况日志后台邮件回传；邮件配置与验证见[精简版维护说明](README_lite.md)。旧发行包保留原样。Windows 源码入口为 `app.py`，需要 Python 和 `requirements.txt` 中的依赖；Mac/Linux 可使用 `run.sh`。

## 启动

- Windows 64位：完整解压后双击 `MissionB.exe`，无需另装 Python。保留 `_internal` 和 `.browsers`。
- macOS：双击 `install-macos.command`，以后用 `start-macos.command`；也可在该文件夹运行 `bash run.sh`。
- Linux：运行 `bash install-linux.sh`，以后运行 `bash run.sh`。
- Mac/Linux 首次安装会下载独立 Python、依赖和 Chromium。Linux 系统组件缺失时会询问是否安装，可能需要管理员密码。环境保存在工具文件夹，安装日志在 `.runtime`。Mac/Linux 安装逻辑已有自动测试，未完成实机验收。

进入“API设置”，填写自己的 DeepSeek 密钥并应用，再导入或粘贴数据。密钥只保存在当前程序内存，退出后需重填；命令行运行也可通过 `DEEPSEEK_API_KEY` 环境变量提供。发行包不包含作者密钥、任务或缓存。

默认调用官方 `https://api.deepseek.com` 的 `deepseek-flash`。每个新页面通常两次结构判断，受每批调用上限限制。网页正文会发送给 DeepSeek；原始上传表及其数量不发送。工作台显示调用次数和 tokens，实际费用以服务商账单为准。

也可选择“已有区域规则”，不调用 API，只适用于已有配置的来源。工作台仅监听本机。关闭网页不停止后台；请用左下角“退出工具”。

## 核验口径

范围为提供的师资入口及同栏目分页，不自动扩展其他栏目，不访问教师目标页。不核实身份、在职状态、职称、邮箱或全院完整性。

名单条目真实存在的 HTTP(S) 链接按源保留，包括条目指向学院首页、英文姓名、同名不同 URL、集体介绍。仅按结构排除导航、面包屑、分页、页脚和相关推荐。无链接的纯文字不编造网址。

重复 URL 按一条比较。仅协议 http/https 不同，其余部分相同，不单独判错；保留路径、参数和片段差异。最终比较 URL 集合，数量相等但地址不同仍属于差异。

四列汇总为 `大学名 学院名 核验结果 特殊情况说明`：

- `正确`：全部指定来源和可识别分页完成核验，链接集合符合现有规则。
- `错误`：已确认原表缺少或多出链接，即使自动修正后仍为错误。
- `特殊情况`：无法可靠判定，需要人工处理。网页无法访问、分页不完整、名单不明确、模型判断不一致等均使用此分类，已知原因放入“特殊情况说明”。

说明允许为空，原因不明也不能判为正确或错误。同学院有多个独立核验分组时，已有分组确认差异则汇总为错误，其他分组未完成的原因仍保留在说明列。界面、四列汇总下载及详细工作簿中的“核验汇总”使用同一分类。详细日志、差异和证据保留；历史文件不改写，历史下载标明旧格式。

网页失败或不确定不会当成零链接，不会据此清空原表。生成的新表不覆盖上传原件。结果基于核验当时页面，不能反推历史网站的状态。

## 怎样限制错误

模型只选择实际网页节点编号，程序从原件枚举网址。两次独立提示的选择必须一致，检查全部实际锚点而非只比较总数；页码有声明时检查覆盖。整页误选、零链接、脚本目标不明和分歧都保留待核。

每次运行重新取得网页。只有清理后的完整页面、来源 URL、模型和判断代码版本完全相同，才复用不超过7天的合格缓存，并重新验证节点。内容或判断版本变化会重新调用。

这能降低误判，但同一模型两次一致仍可能共同漏选区域，不能据此承诺任意高校100%准确。新网站建议首次抽查“逐条证据”中的未计入链接及完整分页。隐藏脚本、复杂交互、图像内没有实际超链接的名单、访问限制等可能需要人工。

`data` 保存任务、输入、HTML原件、每条计入/未计入记录、模型回答、用量和摘要。转发软件请用干净发行包，不要把个人 `data` 一并发送。
