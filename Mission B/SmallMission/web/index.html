    A SMALL, FOCUSED TOOL

    使用说明

    回答一个问题：通过这个师资页获得教师主页链接，还需不需要人工介入？

    三步完成

    1. 上传“个人url＋师资url”双表 Excel，或粘贴／上传原有四列格式。双表的两张表按学校、学院名称对应，不按行号配对；可上传多个学院的文件。
    2. 查看预览，修正行号提示的格式问题，再开始核验。
    3. 下载“原表是否出错”汇总表：只有大学名、学院名、是否出错三列，同一批多个学院放在一张表中。需要追溯时另下载详细核验表。

    汇总表怎么看？

    Yes：原表和官网URL分别去重后，确认有缺少或多出，即使已自动修正仍为 Yes。重复本身不判错；仅 http/https 不同且其余地址相同也不单独判错。No：全部指定来源及其分页已核验且原表吻合。学院网页无法访问：来源访问失败，不能据此认定原表错误。网页可访问但名单结构尚未适配等情况显示“未完成核验”，原因在工作台查看。

    详细结论怎么看？

    原表吻合 原输入与当前源页面的链接逐项一致。已自动修正 原输入有缺少、范围外、重复或协议写法差异，已按源页面生成新表。两种都可以是“无需人工”。

    需人工介入 来源无法读取、名单区域尚未适配、分页未读全或脚本目标不确定等。此时“不确定”不会被当成零链接；请查看原因与原始输入。

    本版适用范围

    已配置本批验证过的名单页面。新师资URL需要核实其名单区域后才能自动判定。

    输入格式兼容不等于网站结构通用。本版不调用大模型，不会凭猜测把整页导航、新闻和其他栏目当作教师链接；陌生页面会明确留待处理。

    计数与边界

    • 统计的是链接，不是人数。同一URL展示多次只保留一条；同名不同URL不会按名字合并。
    • 给定师资页及同栏目的分页合并去重后对账，跨页重复不会重复计入。未读取全部来源时不自动删除原表链接；不自行扩展到未提供的栏目。
    • 空链接、#占位和没有可见内容的空锚点单独记证据。已给出HTTP地址但疑似指向首页的姓名链接按源保留并提示。
    • HTTP/HTTPS差异显式记录为“按源修正协议”，不推断目标页面等价。
    • 核验基于本次取得的页面。不能据此推断历史采集当时的准确度，也不验证邮箱、职称、教师身份或全院完整性。

    运行与保存

    无需 DeepSeek API、账号或付费服务。抓取学校网站仍需要网络；页面响应慢或限制访问时可能无法完成。工作台只监听本机，关闭浏览器标签不会结束任务；通过左下角“退出工具”关闭后台。

    数据与结果在工具文件夹的 data 子目录，原始输入不会被覆盖。发给其他人时使用干净的发行压缩包；不要把自己的 data 文件夹一起发出。

    macOS/Linux 自动安装版首次运行会联网安装独立 Python 环境、依赖与 Chromium。浏览器组件无法安装时，请按压缩包内说明处理。
