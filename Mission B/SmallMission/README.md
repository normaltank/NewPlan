## 本次约定

输入四列：**学校、学院、师资url、教师url**（也接受“教师个人url”表头）。

针对给定师资 URL **本页的教师名单区域**，枚举实际提供的可点击教师条目链接，与输入表逐项核对。页面中的分类分组全部读取，不进入其他独立师资栏目。检测到分页时留下待处理项，不静默扩大范围。

- 不访问教师个人页，因此个人页 404、超时或没有正文不会导致剔除。
- 不核验职称、邮箱、履历、人员任职关系，不推断全院人数或全院完整性。
- 不同 URL 即不同链接；不按同名合并。一个 URL 在多个分类中重复出现时，保留全部来源证据，四列表只保留一次。
- 英文、生僻字、姓名中的空格、兼职星号都不作为过滤条件。
- 空 href、单独 `#` 是没有目标的占位；没有可点击文字或图像的空锚点不作为个人页链接。这些仍进入证据表。
- 姓名链接给出了明确 HTTP(S) 地址，即使看起来指向学院首页，也照源保留并提示。本任务不替官网纠正目标、不猜测新地址。
- 保留参数和有意义的锚点。HTTP/HTTPS 不静默合并；只有主机、路径、参数、锚点一致且可一对一对应时，明确记录“按源修正协议”。严格地址差集也单列。
- 网站可能已经变化。报告是“输入表相对本次官网快照的差异”，不能证明历史采集当时的准确率。

## 是否需要人工介入

名单取得、区域规则适用、所有链接可明确逐项对账时：原表吻合或自动修正后均可判“无需人工”。

来源访问失败、返回空页面、名单区域不明、动态目标无法确定、出现分页或 Excel 超链接与显示值冲突时：判“需要人工介入”。不能将访问失败当零结果，更不能清空输入表。

`source_plans.json` 保存这批入口的名单区域配置及初次取证依据。当前8个正常页面经过代码侧逐项检查；两个取不到名单的入口没有虚构配置。这里的“无需人工”指本配置下的链接核验，不表示新站点无需准备规则。未知入口默认待处理。

## 运行

在本目录运行：

```powershell
.\run.ps1
```

每次在 `outputs/时间戳/` 生成新结果，不覆盖旧运行。优先使用本目录 `.venv`；没有时只借用已有 OpenSource Python 环境，不安装、更新或修改那个环境。

独立机器可创建自己的环境（Python 3.11 或更新版本）：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m playwright install chromium
.\run.ps1
```

不需要模型 API 或密钥。浏览器用于来源页普通请求失败后的正常加载，不连接已有用户浏览器、不处理验证码。

指定输入和输出（输出必须仍在 SmallMission 内，且使用新目录）：

```powershell
.\run.ps1 --input "D:\另一个输入目录" --output outputs\another-run
```

离线回放：

```powershell
.\run.ps1 --replay outputs\live-20261015-final --input outputs\live-20261015-final\inputs --output outputs\offline-check
```

回放只验证保存页，不声称网站当前仍相同。

## 查看结果

- `report.html`：直接用浏览器打开，无需启动服务器；学院结论、差异、人工待办、各学院下载链接。
- `MissionB_核验结果.xlsx`：学院结论、逐项对账、官网链接证据、修正后四列表、待人工处理原始行、官网提示、口径说明。
- `corrected/`：已完成学院的四列修正表。未完成学院不生成空修正表。
- `inputs/`：原输入完整副本。原位置的 Excel 不会被改写，运行前后校验摘要一致。
- `results.json`：机器可读完整对账结果。
- `manifest.json`：输入、代码和配置摘要、依赖版本、时间、运行模式及 API 调用数。
- `evidence/`：师资页响应、HTML、状态及摘要。个人主页不抓取。

`probe_sources.py`、`probe_browser.py` 与顶层 `evidence/` 保留本次配置准备的原始探查材料；正常使用只需要 `run.ps1` / `audit.py`。
