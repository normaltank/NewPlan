# Mission B · 师资链接核验 2.2

这是独立的小工具，不连接原项目数据库，不需要 DeepSeek 或其他模型 API。
支持原有四列和新版“个人url＋师资url”双表，核对指定范围的教师链接。可下载只有“大学名、学院名、是否出错”三列的一张汇总表，每个学院一行；详细差异和证据另行下载。

## Windows 解压双击版

1. **完整解压** `MissionB-Windows-x64-v2.3.0.zip`，放在当前用户可写的文件夹（支持中文和空格路径）。不要直接在压缩包中运行。
2. 双击 `MissionB.exe`，默认浏览器会打开工作台。无需安装 Python，也无需填写任何 API。
3. `MissionB.exe`、`_internal` 和 `.browsers` 必须放在一起，不要只复制 exe。`.browsers` 在部分系统中显示为隐藏文件夹。
4. 用左下角“退出工具”结束后台；只关网页标签不会结束任务。再次双击会回到已运行的工作台。

这是 Windows x64 程序。可写入其所在文件夹才能保存任务。文件未进行商业代码签名。

## macOS / Linux 自动环境安装版

完整解压 `MissionB-Mac-Linux-v2.3.0.zip` 到自己可写的文件夹。**无需预装 Python，也不需要模型 API。**

- **macOS：首次双击 `install-macos.command`**，安装完成后自动打开工作台；以后双击 `start-macos.command`。
- **Linux：在解压后的文件夹打开终端，执行 `bash install-linux.sh`**；以后运行 `bash run.sh`。部分文件管理器也支持右键脚本“在终端运行”。
- 两个入口都支持首次安装和再次启动。无需先手动激活环境。
- Windows 源码运行仍需 Python 3.11+，双击 `start-windows.cmd`。普通 Windows 用户使用同版本独立 exe 包。

首次联网下载固定版本 uv 0.13.1（逐平台 SHA256 校验）、工具专用 Python 3.12、锁定版本的依赖及 Chromium。需要访问 GitHub、PyPI 和 Playwright 浏览器下载服务，耗时随网络而变化，建议预留 1 GB 磁盘空间。后续启动复用已安装组件，仍会检查浏览器能否启动。中途失败不会标记安装完成，恢复网络后重新运行即可。

环境放在工具目录内的 `.runtime/`、`.venv/`、`.browsers/`，不会替换系统 Python，也不改 shell 配置或全局 PATH。Linux 缺少浏览器系统库时会询问是否通过系统包管理器补装，需要使用者输入 `y`，且可能要求管理员密码；选择跳过会保留已下载的环境。卸载工具目录不会卸载这些共享系统库。

支持目标：**macOS 14+（Intel / Apple Silicon）；Debian 12/13、Ubuntu 22.04/24.04/26.04（x86_64 / ARM64）**，依据 [Playwright 系统要求](https://playwright.dev/python/docs/intro#system-requirements)。其他 Linux 发行版未承诺支持，Alpine/musl、32位系统不支持。使用网页工作台需要桌面浏览器；本包不是远程服务器部署版。

本次在 Windows 上验证安装流程的独立环境、脚本分支和原有程序回归；**macOS/Linux 尚未实机验收**。平台下载分支测试不等同于实际系统安装成功。

### 首次启动排查

- Mac 双击无反应、权限不足：在终端进入解压文件夹，运行 `bash run.sh`。若系统安全设置阻止打开，请按系统提示核验来源并允许该文件；不要关闭系统安全保护。
- 提示目录不可写：完整解压到个人目录，例如“文稿”，不要在压缩包或只读磁盘内运行。安装后尽量不要移动目录；换电脑请重新解压干净发行包再安装，只复制需要的 `data/`。
- Linux 缺少系统库：第一次会询问是否补装；稍后也可运行 `bash run.sh --system-deps`，仍需确认并可能要求管理员密码。仅在受支持的 Debian/Ubuntu 上提供自动补装。
- 网络下载失败：恢复网络后重新运行，原安装日志在 `.runtime/install.log` 和 `.runtime/setup.log`。需能连接 GitHub、PyPI 和 [Playwright 浏览器下载服务](https://playwright.dev/python/docs/browsers)；工具不会绕过证书校验。Linux 需要系统自带 `curl` 或 `wget`、`tar`、`sha256sum` 或 `shasum`。
- 仅安装不打开：运行 `bash run.sh --setup-only`。仅检查已有环境：`bash run.sh --check`（不安装、不下载）。这些命令也适用于 Mac。
- 页面无法打开：再次启动工具；它使用自动分配的本机端口，不与原工作台的 8767 端口绑定。应用日志在 `data/app.log`。Mac 可用 Command+Shift+. 显示隐藏的 `.runtime` 文件夹，Linux 文件管理器通常用 Ctrl+H。
- 网站拒绝访问、浏览器读取失败：这会成为“需要人工介入”的核验结果，不会凭空删除教师链接。

## 输入方式

### 新版双表 Excel

一个工作簿包含两张表（按表头识别，不强制 Sheet 名）：

- `个人url`：学校、学院、教师个人url。
- `师资url`：学校、学院、师资url。

同一学院可以提供多个师资URL，每个链接一行。两张表按学校和学院名称对应，顺序可以不同；支持合并单元格、普通超链接和重排表头。个人URL表可以只有表头，此时核对该学院缺少的链接。同一学院不要同时上传四列表和双表，以免混淆逐来源核验与学院合并核验的范围。

双表会先读取该学院全部给定师资页，再合并去重对账。某链接出现在两个师资页上只计一个URL，两个出处都保留；一个来源失败时，不把其余页面中暂未找到的输入链接删除。同一栏目中识别出的分页会自动继续读取，直到读完；不扩展其他栏目。分页读取失败时保留原表，不冒充已核验通过。

### 原有四列表／粘贴文本

可同时粘贴文本并选择多个文件，每条教师URL一行。

```text
学校    学院    师资url    教师url
示例大学    示例学院    https://example.edu.cn/faculty/    https://example.edu.cn/person/1
```

支持：

- `.xlsx`、`.xlsm`、旧版 `.xls`；多Sheet、合并单元格、普通超链接、字面量 `HYPERLINK` 公式。
- `.csv`、`.tsv`、`.txt`；UTF-8、带BOM的UTF-16、GBK/GB18030。
- 从 Excel 复制的制表符文本、CSV、Markdown 表格；无空格名称也可用空格分列。
- 四列无表头的文本，或包含四个字段的常用表头别名。带表头时支持调整列顺序和额外备注列。

空教师URL允许存在，但必须保留第四列。`无详细页`等非URL标记保留在原始行和证据中；只有名单可靠时才从最终纯链接表移出。学校、学院和师资URL不能为空。含空格的学校/学院名称请用制表符、CSV或Excel。

遇到缺列、无效来源地址或显示URL与实际超链接冲突，预览会指出文件、Sheet和行号，修正后才能运行。工具不会执行Excel宏或任意公式。模板在 `templates/`，也能从页面下载。界面中的“填入示例”仅演示格式，故意放了一个示例地址，不能当作已经正确的完整教师表。

单文件最大10MB，每批最多50个文件、50,000条输入。网页上传总量建议不超过20MB，较大数据请分批处理。

## 如何读结果

“原表是否出错 · 汇总表”按钮下载单个 Excel，只有一张工作表、三列：**大学名、学院名、是否出错**。批量上传4个学院即汇总为4行，不按学院拆成4份。这个结果判断原始上传数据，不以自动修正后的状态或是否需人工介入代替。

- `Yes`：已确认原表有差异（具体口径见下方简表说明）。
- `No`：所有指定来源已核验，原表按简表口径无误。
- `学院网页无法访问`：师资来源访问失败，未能判定原表；不代表原表有错。
- `未完成核验`：网页可取得，但名单区域未适配、范围未明确等。原因在工作台；不能伪装成网页无法访问或原表错误。

如需追溯，可另下载详细核验表或完整证据。旧版历史任务保留原文件，只有新运行提供新增汇总表。

简表说明：原表和官网URL分别去重后逐项比较，存在缺少或多出的链接才为 Yes。重复本身不判错；域名、路径、参数、锚点相同，仅 http/https 不同也不单独判错。数量相同仍比较具体地址，不能让漏一条、多一条相互抵消。非URL标记留在详细报告中，不冒充链接。访问失败等执行问题不计为原表错误。

|结论|含义|
|---|---|
|无需人工，原表吻合|已有输入与当前给定名单提供的链接集合吻合|
|无需人工，已自动修正|原输入有漏采、多采、重复、非URL标记或协议写法差异，工具已生成修正后的四列表|
|需要人工介入|来源不能读取、名单区域未适配、分页未能全部读取或脚本目标不能确定；不自动增删原始输入|

**“无需人工”并不代表输入表原本准确。** 同时看“原始数据”状态以及缺少、多出、重复和协议修正数。

详细核验 Excel 包含学院结论、逐项对账、官网链接证据、修正后四列表、教师链接来源映射、待人工处理原始行、官网提示和口径说明。修正后四列表每个URL只留一行，师资URL填写实际发现它的第一个来源；来源映射表保留全部出处。另有分学院修正表压缩包；同一学院提供不同师资URL时文件名加来源编号，避免相互覆盖。

“完整结果与证据”压缩包包含离线 HTML 报告、Excel、原始输入副本、来源快照和运行记录。解压完整结果后打开 `report.html`，相邻下载链接才可用。

## 必须理解的范围

1. 统计的是链接集合，不是实际教师人数。同一URL展示多次只计一个；同名不同URL不按姓名合并。
2. **读取给定师资URL及同栏目的可识别分页**，包含页面上的多个名单分组。四列表按来源栏目核验，双表按学院合并全部给定来源与分页，不自动转去其他栏目。不请求教师个人主页，不因其404或超时移出。
3. 空href、`#`占位、无文字也无图片的空锚点不冒充教师主页。确有HTTP目标但指向学院首页的姓名链接按源保留并提示。
4. HTTP/HTTPS差异显式记录为“按源修正协议”，不假定两个页面相同。
5. 以本次取得的名单快照为准，不倒推历史采集准确度，不承诺全院真实教师名单完整，也不核对职称、邮箱或身份。
6. **本版补齐用户新增37个入口的名单区域配置，并保留原8个正常来源的配置；另2个来源仍未读到可靠名单。不是任意高校网站自动通用适配器。** 输入新URL时，需先核实其名单区域；未知结构会转人工，而不会用整页链接猜测。

当前正常配置：山东理工大学农工食品、常州大学城建、江汉大学马克思主义、沈阳航空航天大学设计艺术、湖北汽车工业学院汽车材料、湖南大学人工智能与机器人、皖西学院文化传媒、青海师范大学体育。具体URL见 `source_plans.json`。

## 保存、隐私与分发

- 工作台仅监听 `127.0.0.1`，每次启动生成本机会话凭证；不开放到局域网，不含作者的密钥和令牌。
- 所有任务数据在工具目录的 `data/` 中。来源网站会收到正常网页请求；工具没有模型API调用、遥测上传或账号登录。
- 原文件不会被覆盖，上传副本和结果会留在本机。执行中断时标明未完成，不把部分结果当作完整交付。
- 发给其他人请使用**干净发行ZIP**。不要把使用后产生的 `data/` 一并发送。卸载为删除自己解压的文件夹；有用结果请先保存。

## 开发与核验

在已安装依赖的本地环境运行：

```text
python -B -m unittest test_audit test_distribution test_bootstrap test_multisource -v
python -B app.py
python -B audit.py --input 输入目录 --output outputs/新的输出目录
```

`audit.py` 是命令行核验核心；`input_adapter.py` 处理输入；`app.py` 提供本机网页；`reporting.py` 导出证据；`source_plans.json` 保存经过核实的页面配置。输出必须放在工具独立子目录，防止混入其他工作流。

新增来源配置前应实际查看页面、确定名单区域，并保存样本进行对照；不能仅靠链接数相同就宣布通过。`requirements.txt` 锁定依赖版本；运行记录保存实际版本与源码摘要。第三方组件遵守各自许可证，Windows包随附 `third_party/` 与浏览器许可文件。

## 2.3 更新

修复新批次网页缺少名单配置而无法核验的问题；自动读取同栏目分页，保留每页来源和失败原因。浏览器复用会话，记录最后实际导航响应；连接失败有限重试、同站请求间隔至少3秒。需要浏览器的站点后续直接复用浏览器；若站点明确提示IP进入黑名单，暂停本轮后续请求并保留失败原因。已经取得静态正文的未知结构不再重复打开浏览器。

核验只比较来源内的链接，不能凭新页面计数增加断言全院人员完整。网站仍拒绝访问时明确报告，不绕过验证码，不将失败当作原表错误。一次学院最多读取200个来源页，超限会明确报告未完成，不静默截断。

输入格式适配不等于网站适配。本次用户新批次的10个文件／37个入口已经通过格式解析检查；这些新入口并未因此自动获得已核实名单区域配置，不把读取成功或计数一致当作完整性验收。
