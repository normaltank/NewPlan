# Mission B 维护入口

本目录继承 [OpenSource 授权与维护规则](../AGENTS.md)。修改前读 [Mission B 入口](README.md)；核验边界以 [完整版的核验口径](SmallMission/api_workbench/README.md#核验口径) 为准，精简展示和回传行为读 [精简版说明](SmallMission/api_workbench/README_lite.md)。根目录 CONTEXT 的人员字段、身份合并和三表交付属于主工作台，不替换 Mission B 的 URL 核验契约。

## 工作流

开始维护或发现新的独立根因时，先读 [公共 Matt 工作流](../docs/agents/workflow.md) 和 [Mission B 维护执行约定](docs/maintenance-workflow.md)，确定单任务或拆分实施路线。技能来源、子代理配置和通用收尾条件继承公共工作流；执行前读取实际选中的技能，按步骤保留证据。

任务与规格使用 [NewPlan Issues](../docs/agents/issue-tracker.md)，标签和领域文档继承根目录配置。其他对话可作为用户指定的历史资料；任务执行按技能与验收条件推进，不按“主任务／副任务”对话名称路由。需要独立审查时使用该技能规定的审查步骤，不用读取其他对话代替审查。

## 维护落点

查版本、历史报告、日志或更新文档时读 [档案索引](docs/README.md)。每个主题只更新其负责文件；历史报告保留当时事实，新的复现和验证写入新维护目录。交付前核对入口与链接、改动范围及证据；本次未验证的能力明确保留限制。
