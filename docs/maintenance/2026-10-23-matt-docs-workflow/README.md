本次从用户技能目录读取 `ask-matt` 路由，采用 `writing-for-agents` 整理文档，并用 `domain-modeling` 记录已有业务术语。AGENTS 增加读取工作流的条件；工作流关联任务、验证、双维度审查和 PR。临时技能子代理与独立用户对话分别说明；本轮没有调度独立用户对话。

根目录 REPORT 改为兼容入口，正文移至 [历史报告](../../history/initial-report-20261014.md)。新增维护索引，当前知识、历史结论、试验与任务进度各归其负责入口。Markdown 清单见 [档案清单](inventory.json)；既有历史记录、生成报告和 Mission B 文档保留原状。

## 核验方式与材料

- [搬移保真](archive-proof.json)：取基线 `REPORT.md` 原始字节，归档时仅给相对 Markdown 链接补 `../../`；按记录反向替换后，应逐字节一致。旧父级 CONTEXT 与本机 `runs/` 的可用性在历史索引说明。
- [验证结果](validation.json)：检查当前改动文档的本地链接和锚点、归档正文保真、Markdown 分类覆盖、业务契约与运行文件未变。所有哈希基于记录的版本或本轮工作树，不代表未来状态。
- 规范与需求审查：按 `code-review` 分别回报到 Issue #3，并记录后续处理；提交后的实际版本和 CI 结果从关联 PR 读取。

这是文档和工作流整理，没有执行真实采集或付费调用，没有验证新的学院完整性。独立工作树避开主工作区的 Mission B 并发修改；运行原件、复核决定和本机配置不在本次变更范围。
