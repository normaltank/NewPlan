# 项目访问与修改授权

所有者与修改授权的规则统一见 [AGENTS.md](../AGENTS.md)。本文件用于需要修改仓库权限、凭据或保护规则时定位核对事项，不以文档代替远端实际配置。

当前 Git 根目录为 OpenSource，远端为 `normaltank/NewPlan`；所有者已将其设为公开仓库。父目录的旧 Git 元数据继续服务其他关联工作树，不属于本项目的提交范围。旧 MyPlan 工作区代码和资料已按所有者要求删除，本地清理没有删除旧 GitHub 仓库。实际远端、分支和保护状态在操作前读取 Git／GitHub 确认。

修改权限或保护前，核对仓库所有者、协作者、待接受邀请、分支／标签 ruleset 的生效范围与绕过身份、主分支实际应用规则及必需检查。不能把旧配置快照或旧项目文档中的规则名称当作今天的状态，也不能为通过检查或合并而降低保护。

所有者凭据代表所有者身份；它不能区分本人和获授权工具。凭据只存受控的本机加密存储或部署环境，文档、日志与代码中不保存密钥。未获得所有者授权的外部修改请求只作为待核资料，不改变工作区或远端状态。
