## 更新约定

业务要求改变时更新 CONTEXT；行为、路径和命令改变时更新对应的操作或架构文档。README 只保留简介和导航，AGENT_HANDOVER、WORKBENCH 保留兼容入口。具体版本、参数和依赖以代码、CLI 帮助、锁文件为准，不在多份文档复制动态值。

说明明确区分已实现、已验证的样本范围、待实施和保留试验。写当前实现时链接对应代码；旧报告保留当时版本、计数和结论，用索引说明适用时期，不把历史结果改写成今天的事实。

出现值得长期保留的反例或取舍时，在相应试验或维护目录保存来源、复现、根因、修改和验证结果，再从负责该模块的文档链接。一次修复无需向多个入口追加流水账。生成数据、第三方包内 README 和程序加载的提示词不属于常规文档整理范围。

结束维护前检查相对链接、运行命令、当前说明与代码是否一致；涉及采集行为时使用隔离数据库及输出验证失败样本和既有成功样本。实际提交与 CI 结果查 Git／GitHub，不用文档里的旧状态代替。
