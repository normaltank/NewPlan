# Triage Labels

| Matt 角色 | 本仓库标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 待维护者判断 |
| `needs-info` | `needs-info` | 等待补充信息 |
| `ready-for-agent` | `ready-for-agent` | 需求明确，可由 agent 处理 |
| `ready-for-human` | `ready-for-human` | 需要人工处理 |
| `wontfix` | `wontfix` | 已决定不处理 |

技能提及任务角色时使用上表标签。标签表示任务状态，不等于新授权；例如 `ready-for-agent` 不自动允许采集、付费调用或部署。已有同名标签保留，不覆盖其颜色与说明。以后可以直接编辑本文件调整映射。
