# 教师资料采集

首次使用请运行 `setup.bat --web` 安装依赖。随后在 Windows 运行 `web.bat`，在 Linux 运行 `./web.sh`，打开窗口显示的本地网址。

1. 选择原格式 Excel 文件，可同时选择多份。页面先检查文件、学院关联和重复条目，不会立即访问网页。
2. 查看条目数量和导入问题，点击“开始采集”。进度显示实际已处理条目；需要中断时点击“暂停处理”，当前页结束后暂停，之后可继续。
3. 处理完成后，按学校下载“教师 Excel”和“全文与来源 ZIP”。待核或失败的条目及原因在 ZIP 异常明细中，已取得的完整原文和来源一并保留。

没有输入文件时，可点击“离线试用 / 查看示例”，再点击“开始离线试用”。示例使用虚构本地材料，不访问网站。

关闭或刷新页面可恢复进度，请保持服务窗口运行。重新启动程序时保留同一份 `data` 文件夹。页面提示服务尚未开放时，请联系维护人员配置。

每批最多 20 个 `.xlsx`，合计 20 MiB。保留 Excel 原表，不修改 `Sheet1`、`Sheet2` 及原表头。处理结束不代表全院教师已采齐；待核信息需要结合原文检查。
